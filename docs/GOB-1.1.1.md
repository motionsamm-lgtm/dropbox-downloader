# GOB 1.1.1 — Resizable Windows window

## Windows

- Replaced the standard blue title bar with a compact GOB caption in the matte dark theme.
- The window can be resized; input fields, history columns, and action rows adjust with its width and height.
- Added working custom minimize, maximize/restore, drag, and close controls.
- The download engine, resume checkpoints, history, logs, and updater behavior remain unchanged.

## Validation

The Windows build and app-start/close smoke check passed, along with the existing real-transfer, folder recovery, and completion regressions. Mac packaging and existing Mac checks also passed; the Mac interface is unchanged in this release.
